# SFUSD school map

Interactive map of 72 SFUSD elementary schools, 58 attendance areas, and 41 neighborhoods.

## Run locally

```sh
npm install
npm run dev
```

Use `npm run build` to type-check and create a production build.

## Data

GeoJSON files live in `public/data`. School points are from 2025–26; attendance boundaries are from 2024–25 and are historical reference data, not an enrollment or eligibility guarantee.
